# План переработки UI/UX

## Новая структура сайта

- `/` — продуктовая главная
- `/uslugi` — услуги
- `/company` — о компании
- `/faq` — вопросы и ответы
- `/contacts` — контакты + карта
- `/privacy`, `/cookies` — юридические страницы
- `POST /bot.php` — API заявок (без изменений контракта)

## Главная (последовательность)

1. Header (логотип, nav, телефон, CTA, mobile menu)
2. Hero: H1, пояснение, CTA «Бесплатный замер», вторичная ссылка на услуги, тематическое фото
3. Доверие: партнёры Montblanc/Mako, гарантия 15 лет, бесплатный замер, монтаж за 1 день
4. Проблема / решение: холод, шум, старые окна → профили и монтаж под ключ
5. Услуги: карточки со ссылкой на `/uslugi` и якорями
6. Что входит «под ключ» (из существующего content)
7. Как работаем: 4 шага (замер → договор → изготовление → монтаж)
8. FAQ-превью (3–5 вопросов) → `/faq`
9. Форма заявки `#form`
10. Карта производства
11. Footer

## Внутренние страницы

- Общий layout shell
- Page hero / H1 + lead
- Breadcrumbs
- Контент + CTA на `#form` или `/contacts`
- Единые токены и типографика

## Общие компоненты

`AppHeader`, `AppFooter`, `AppButton`, `AppSection`, `AppContainer`, `AppBreadcrumbs`, `ContactForm`, секции `home/*`, `SeoJsonLd` / composable `usePageSeo`

## Визуальное направление

Светлая нейтральная база, акцент `#003770`, DM Sans, контейнер 1200px, спокойные отступы, без неона и glassmorphism. Mobile-first.

## Сохраняемые функции

Форма → Telegram, контакты, карта, Метрика (env), верификации, реальные факты бизнеса.

## Перерабатываемые

layout/default, header, footer, hero, services, how-works, form-section, все pages, app.vue SEO, fonts, vars.

## Порядок внедрения

1. Docs → 2. env/runtime → 3. токены/UI → 4. shell → 5. страницы → 6. SEO → 7. проверки

## Риски

Ротация Telegram-токена; не публиковать непроверенные цифры/цены из неиспользуемых блоков; внешние ссылки на `/#about`.

## Критерии готовности

См. ТЗ этап 15 + локальный `build` / `typecheck` без деплоя.
