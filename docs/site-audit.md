# Аудит сайта «Окна Арсенал»

Дата: 2026-07-13. Baseline: `npm run build` — успешно (Σ ~22.7 MB / 8.97 MB gzip).

## 1. Текущий стек

| Слой | Технология |
|------|------------|
| Framework | Nuxt 3.14 (SSR / Nitro) |
| UI | Vue 3, file-based routing |
| Стили | Sass (+ scoped SCSS в компонентах) |
| Изображения | `@nuxt/image` |
| Иконки | `lucide-vue-next` через `LucideIcon.vue` |
| Формы | Клиентский `$fetch` → `POST /bot.php` → Telegram Bot API |
| Аналитика | Яндекс.Метрика (жёстко в `app.vue`) |
| Деплой | PM2 + nginx + Let's Encrypt (`deploy.sh`) |
| Пакетный менеджер | npm |
| Тесты / lint | отсутствуют |
| i18n | нет (только RU) |
| Auth / admin | нет |

## 2. Архитектура проекта

```
app.vue                 — глобальные SEO + Метрика + JSON-LD
layouts/default.vue     — ОШИБКА: содержит контент главной
layouts/inner.vue       — Header + main + Footer для внутренних
pages/*                 — маршруты
components/home/*       — секции главной
server/routes/bot.php.post.ts — заявка в Telegram
public/content.js       — тексты (часть не используется)
assets/sass/*           — глобальные стили
```

Рендеринг: SSR (публичный HTML доступен ботам).

## 5. Пользовательский путь

1. Главная → понять услугу → CTA «заявка / расчёт».
2. `/uslugi` → выбрать тип объекта → заявка.
3. `/faq` → снять возражения → заявка.
4. `/company` → доверие → заявка.
5. `/contacts` → телефон / карта / заявка.
6. Форма → Telegram → звонок менеджера.

## 6. Проблемы интерфейса

- Контент главной в layout, а не в page.
- Hero без пояснения и CTA.
- Нет логотипа-бренда в шапке как hero-сигнала.
- Слабая продуктовая последовательность (нет «проблема → решение», «этапы», финального CTA).
- Якорь `/#about` ведёт на форму, не на «о компании».
- Карточки услуг на главной — абстрактные преимущества без ссылок.
- Footer без навигации и юридических ссылок.
- Год в футере: 2025.

## 7. Мобильная версия

- Нет рабочего mobile drawer (в CSS есть `.drawer`, в Header — нет).
- На узких экранах навигация сжимается, но не скрывается в меню.
- Карточки услуг 3→1 колонки — ок; touch-targets кнопок в целом достаточны.

## 8. Доступность

- Landmarks: header есть, `main` только в inner; на главной `main` отсутствует.
- FAQ: `aria-expanded` есть, нет `aria-controls` / id панели.
- Форма: labels есть; нет `aria-live` для успеха/ошибки; нет состояния loading / double-submit.
- Focus: у FAQ `:focus` без видимого кольца `focus-visible`.
- Карта Яндекса — только клиент, без текстовой альтернативы адреса рядом со смыслом секции.

## 9. Производительность

- Google Fonts: 5 семейств через `@import` (используется DM Sans).
- Hero-изображение через обычный `<img>`, не `@nuxt/image`, без приоритета LCP.
- Метрика и карта грузятся без отложенной стратегии (карта — onMounted — ок).
- `vue` / `vue-router` в package.json как `"latest"` — риск недетерминированной сборки.

## 10. Проблемы SEO

- Домен захардкожен; нет `runtimeConfig` для staging IP.
- Глобальный title главной в `app.vue` перекрывает логику страниц при гидрации/дефолтах.
- Статические `sitemap.xml` / `robots.txt`.
- Нет страниц privacy / cookies.
- Нет хлебных крошек.
- Цены в FAQ публикуются («от 10 500 ₽») — уже на сайте; примеры из `content.js` не рендерятся (не поднимать без нужды).

## 11. Дублирующиеся компоненты

- Header/Footer импортируются вручную в двух layout.
- SEO `siteUrl` копипаста в каждой page.
- `about.vue` не подключён; `form-section` с id=`about`.

## 12. Устаревшие / неиспользуемые зависимости

- Неиспользуемые шрифты Inter, Nokora, Poppins, Roboto.
- Блоки `examples`, `keyWorking`, `experience` в `content.js` не на главной.
- Preloader-стили, вероятно, мёртвый код.

## 13. Риски переработки

- Telegram-токен в git history → нужна ротация.
- Ломание якорей `/#about` у внешних ссылок → заменить на `/#form` + редирект-якорь.
- Карта зависит от API-ключа Яндекс.Карт.

## 14. Сохранить обязательно

- `POST /bot.php` → Telegram.
- Контакты, адрес, телефон, email.
- Партнёры Montblanc / Mako, гарантия 15 лет, бесплатный замер, монтаж за 1 день.
- Яндекс.Метрика + верификации Webmaster / GSC.
- Карта производства.
